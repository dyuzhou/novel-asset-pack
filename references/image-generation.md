# 图片提示词与生成记录

提示词按“统一风格 + 主体 + 识别细节 + 视图/构图 + 氛围光影 + 质量约束 + 本项目世界观约束”组装。统一风格和禁用元素从 `visual_style.json` 读取，提示词完整文本、版本、参考图和生成参数写入资产/任务记录，确保可重生成、可比较。

**资产图模式**只描述人物/场景/道具本体和标准视图，不自动带入当前剧情人物或无关场景。**分镜图模式**必须明确引用已审核人物、场景和道具版本，再加入当前剧本动作、空间关系与光线。人物多视角始终引用主参考图。

`buildImagePrompt()` 是模型无关的确定性提示词骨架；它不会连接或启动图片模型。Agent 应将最终提示词交给真实可用的图像能力，并只记录真实输出。

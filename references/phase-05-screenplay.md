# 阶段 05 · 原著忠实型剧本

将小说文字转成可视化影视表达，不机械照抄，也不另写剧情。每场记稳定 ID、章节、原著事件 ID、场景、人物、时间/天气和片段。片段类型只能是 `DIALOGUE`、`NARRATION`、`INNER_MONOLOGUE`、`ACTION`、`ENVIRONMENT`。

长篇背景可以用有明确来源的画面、旁白、内心独白或环境表达；无对白镜头不应被一律快速略过。预计时长按对白/旁白实际字数与语速、动作复杂度、无对白画面的叙事价值分别估算，不为套固定秒数拖慢或删掉情节。脚本提供语音时长估算工具；估算值需要按目标表演方式复核。

建立逐事件 `story_coverage`：每条原著事件都有对应剧本场次。任何遗漏、新增或矛盾都阻断提交并展示原著对账证据；不得用 Agent 自评替代用户批准。

# world-pass — 世界观与势力提取

输入：原著文本（全文或指定章节范围）。
输出：`assets.json` 的 `world` 六项 + `factions` 数组 + `project.style_anchor` 草案。

## 只整理，不创作

本 pass 的纪律：

- **只归纳原文给出的设定**。原文没写的字段，写"原文未明示，按同类设定暂定：…"，并在 `pipeline.steps[world].note` 里列出暂定项，等用户确认。
- **不改写、不补设定、不发明新势力**。原文提到但戏份极少的势力也要收（哪怕只有一句话描述），因为忠实原著意味着不删。
- 引用关键原文短语放 `note` 或场景/道具的 `source_ref` 里，方便用户核对。

## 提取顺序

1. **世界背景**：时代、王朝格局、仙/凡/魔关系。两三句话讲清世界怎么运转。
2. **修炼/社会体系**：境界或等级名（原文给多少收多少，不补）、晋升代价、体系间的压制关系。
3. **社会结构**：凡人—江湖—修仙（或原文的对应层级）谁管谁。
4. **建筑风格**：材质（青石/木构/竹）、形制（飞檐/穹顶/窑洞）、装饰母题（云纹/兽首）。修仙与凡俗建筑有差异就分开写。
5. **服饰规则总纲**：原文如何用服饰区分阶级/势力/修为。这是后面所有角色服饰字段的依据。
6. **色彩体系**：原文的环境主调（如"云雾缭绕的青灰"）、势力主色、点缀色。

## 势力（factions）

每个原文出现的势力一条。重点三个字段：

- `class_system`：从低到高列全原文出现的阶级。**同一势力内不同阶级必须有服饰差异**（弟子/长老/宗主），写进 `costume_rule`——这是后面生成时不串阶级的依据。
- `costume_rule`：逐阶级写颜色、材质、纹样、配饰、武器。只写原文给的；原文没细写的阶级写"参照上一级，材质略降"这类可执行的梯度，不发明具体纹样。
- `main_color` / `pattern`：**两个势力不得完全相同**（F2 门会打回）。原文没给就按定位取对比色（正道素雅/魔道浓烈之类），并在 note 标注暂定。

`prompt_body` 五段里，主体写该势力的代表性空间（山门、殿堂、营地），背景与细节为空间服务，**不放具体角色**。

## 风格锚点草案

world 完成后，按 `schema.md` 的锚点结构起草 `project.style_anchor`（默认 3D 写实国风仙侠；用户指定了别的风格就按用户的方向重组）。草案交给用户确认——**确认前不开 characters pass，确认后锚点锁死**。

# art-pass — 场景与道具提取

输入：`assets.json`（world/factions/characters 已完成）、原著文本。
输出：`scenes` 与 `props` 数组。

## 场景（scenes）

- **只收原文出现的地点**，主舞台优先（主角反复活动的场所），一次性路过的地点若原文有明确描写也收——忠实原著，不删。
- 同一地点在不同时期面貌不同（被毁/重建/换季节氛围）就建多条，`era` 区分。
- 字段要点：
  - `atmosphere`：可画可核对。"肃穆清冷" 可以；"很有感觉" 不行。
  - `lighting`：时段 + 方向 + 色温（"晨雾侧逆光，冷色调"）。下游每个镜头的光都在这里对表。
  - `key_elements`：≥2 个，观众靠这些认出场景（"百丈崖壁 + 铁索吊桥 + 青石门楼"）。写原文给的，不发明地标。
- `prompt_body` 五段：主体写空间本身，**不出现任何角色**——场景资产和角色资产是两层，混进人的空景会让下游参考图一致性全毁。

## 道具（props）

只收**叙事道具**：有特写、跨章节出现、承载剧情的（信物、法器、身份凭证、关键武器），一般 3–10 件。陈设归场景，一次性手部道具归镜头，不建资产。

- `owner`：归属到势力+阶级（"七玄门弟子"），让下游知道该出现在谁手里。
- `material`：材质+做工+新旧（"粗木，边角磨圆"）。
- `usage`：戏剧功能（"身份凭证，入门时发放"）。
- `source_ref`：`{ "chapter": 3, "quote": "原文短引" }`，方便用户核对，没有就 `null`。
- `prompt_body` 五段：特写视角（首段含"特写"），主体写道具本身，**不含手、不含人**——道具图要被贴进各种镜头，拿着道具的手是最常见的污染源。

## 与上游的衔接

- 势力资产的 `prompt_body`（山门/殿堂等代表性空间）与场景资产可能相似：势力提示词是"这个势力的视觉气质"（报告里给用户看），场景提示词是"具体某一处的出图用提示词"。两者措辞可以呼应，但场景条目必须能独立出图。
- `pipeline.steps[scenes]` / `[props]` 完成后置 `done` 并在 `note` 里写数量与一句话摘要。

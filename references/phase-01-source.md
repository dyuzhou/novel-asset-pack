# 阶段 01 · 原著解析与世界观建立

输入仅限用户提供且授权使用的原著文件和明确章节范围。先建立章节索引，再分批读完所声明范围；保存已读章节、未读章节和缺失文件，不能谎称通读全文。

交付：`world/world_bible.md`、`source_index.json`、`story_events.json`、`characters.json`、`factions.json`、`scenes.json`、`props.json`、`timeline.json`、`asset_registry.json` 初始清单。对重要事实记录章节出处和 `SOURCE_FACT / INFERENCE / ART_DECISION / UNKNOWN` 标签。原著设定冲突应并列记录，不自行修订。

提取人物与人物关系/变化、所有势力和等级、世界与时代、修炼/法术规则、地点、叙事道具、人物出场时间/年龄变化和完整事件时间线。不要从未读内容推断完整世界。

完成后运行阶段 01 质量门并生成审核报告。报告应显示阅读范围、事件数量、出处缺失、矛盾和暂定项。只有用户明确确认后才能进入阶段 02。

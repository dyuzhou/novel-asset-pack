# prompt-style — 提示词结构规范

统一结构（七段）：

```
风格 + 视角 + 主体 + 背景 + 细节 + 光影 + 质量词
```

落到数据上只有一段归你写：

| 段 | 谁写 | 内容 |
| --- | --- | --- |
| 风格 | **脚本注入** | `project.style_anchor`，注入每一条提示词 |
| 视角 | 模型（prompt_body 第 1 段） | 镜头语言：中景/全景/特写 × 平视/俯视/仰视 |
| 主体 | 模型（第 2 段） | 角色=锚点+服饰；场景=空间主体；道具=道具本身 |
| 背景 | 模型（第 3 段） | 环境与位置关系 |
| 细节 | 模型（第 4 段） | 材质、纹理、可画可核对的特写点 |
| 光影 | 模型（第 5 段） | 光的方向、色温、氛围 |
| 质量词 | **脚本注入** | `project.quality_common` |
| 负面词 | **脚本注入** | `project.negative_common`，统一追加 |

`prompt_body` 写法：五段用中文分号 `；` 分隔：

```
视角；主体；背景；细节；光影；
```

**禁止写进 prompt_body**（E3 门打回）：风格词（UE5/PBR/电影级光影/低饱和…）、质量词（8K/超清/稳定构图/无畸形…）、"以参考图"前缀、"负面"字样。这些全部由脚本注入——重复只会让下游提示词又臭又长，还可能在用户改锚点时对不上。

## 示例

**角色 · 基准期**（最终出图提示词 = 注入段 + 你的五段）：

```
中景平视；青年男修，黑色长发束冠，眉目清冷，身着青灰色外门弟子袍，衣料粗麻质感，腰系木牌；站在宗门山门石阶前，远处云雾缭绕，古松与青石建筑隐约可见；侧逆光，冷色晨雾，轮廓光轻微；
```

脚本拼装后下游实际拿到的完整提示词：

```
3D 写实国风仙侠，UE5 引擎质感，PBR 材质，电影级光影，低饱和厚重色调，人物比例写实，服饰符合门派阶级设定，画面稳定统一，禁止 Q 版、卡通渲染、过度美颜；中景平视；青年男修，黑色长发束冠，眉目清冷，身着青灰色外门弟子袍，衣料粗麻质感，腰系木牌；站在宗门山门石阶前，远处云雾缭绕，古松与青石建筑隐约可见；衣料粗麻纹理与木牌刻痕清晰；侧逆光，冷色晨雾，轮廓光轻微；8K 超清，超高细节，稳定构图，无畸形肢体；负面提示词：畸形、多指、模糊、水印、画风突变、比例失调、Q 版、卡通渲染、过度美颜
```

**角色 · 衍生时期**：你照常写五段，脚本自动在开头注入图生图前缀：

```
以参考图为基础，保持面部特征与体型不变，仅调整：<variation_reason>；<风格锚点>；<五段>；<质量词>；负面提示词：<负面词>
```

前缀写死的含义：**脸型与五官以参考图为准只做微调，禁止重新生成**；原著固定特征（断臂/刀疤）以参考图为准保留。

**势力 / 场景 / 道具**：同五段结构。场景主体写空间（无人）；道具首段用特写，主体只有道具（无手无人）；势力主体写代表性空间/人群气质。

## 自查清单（validate 会查，写之前先自查）

1. 五段齐全，分号分隔（E1）
2. 第 1 段含镜头词（E2）
3. 无风格/质量/负面/图生图注入词（E3）
4. 角色时期：主体段含固定主体锚点 + 全部 `fixed_features` 短语（C6）
5. 服饰符合势力该阶级的 `costume_rule`，颜色材质配饰写全

# character-pass — 角色与时期提取

输入：`assets.json`（world + factions 已完成）、原著文本。
输出：`characters` 数组（含每个角色的 `periods`）。

这是全 skill 一致性风险最高的 pass。规则背下来再动手。

## 收谁

- 原文有名字、有台词或有动作描写的角色都收。**忠实原著 = 不删人物、不合并人物**——哪怕只有一句外貌描写的配角也建资产（外貌原文没给就写"原文未描写，按身份暂定"，并标 note）。
- 群众/弟子甲不建资产，用势力资产的 `prompt_body` 覆盖。
- 收录顺序按原著出场顺序，id 用 `char_<拼音或英文>`。

## identity_anchor — 固定主体描述（一致性根基）

每个角色写一段 8 字以上的**客观外貌锚点**：脸型、五官、肤色、发型、体型。
规则：

- **客观可画**："瘦长脸，单眼皮，颧骨微高，中等偏瘦" 可以；"清冷帅气" 不行（每人生成的帅哥不一样）。
- **稳定短语**：这段文字会在该角色所有时期、所有镜头复用，写一次用到底。措辞力求不可替换——换一个词，生图模型就会换一张脸。
- **原著优先**：原文有外貌描写就忠实转写；原文只有气质描写（"相貌普通"），就把气质翻译成可画特征（相貌普通 → 五官端正但不出众，无记忆点）。
- 衍生时期**以参考图生图**，脸型五官只能微调——前提就是每个时期 prompt_body 的主体段都带着同一段锚点。

## fixed_features — 原著硬特征

断臂、刀疤、跛足、独眼、胎记……原文明确写、且跨时期持续存在的身体特征，写进这个字段（逗号分隔短语），并且：

- **每个时期的 `prompt_body` 主体段必须原样包含**（C6 门逐时期检查）。模型换词（"刀疤"写成"伤痕"）都会被打回——这不是较真，是防止下游生成 100 个镜头后疤没了。
- 原著剧情真的消除了该特征（幻化、断肢重生、易容），才允许在新时期的 `variation_reason` 写明依据后不带该特征。
- 这些特征同样约束图生图：参考图里必须有，微调不许抹掉。

## periods — 时期拆分

按**身份/修为/服饰**的变化节点拆期（拆多少期由原文决定，不猜后续剧情）：

- 典型拆法：`外门弟子期` / `内门弟子期` / `金丹期`；或 `少年期` / `青年期`。
- **每个角色恰好一个基准期**（`is_base: true`）：通常是角色出场时的第一个形态。基准期是全角色参考图的源头，外貌写最完整，prompt_body 最讲究。
- **衍生时期一律 `reference_img2img`**：给 `reference_image`（基准期或上一时期的成图路径）+ `variation_reason`（变什么：服饰/年龄/气质；**不变什么：脸**）。生图方式是拿参考图生图、脸型只微调——`variation_reason` 里直接写给下游看，如：

  > 离开七玄门加入黄枫谷：服饰换米黄道袍与玉牌，年龄由少年长为青年，气质转沉稳；脸型与五官以基准期参考图为准只做微调

- **只有原著明确描写的变形才可重开新图**：幻化、易容、夺舍、肉身重塑等，置 `source_described: true` 并引用原文依据。Agent 不得因为"年龄跨度大""描写变了"就自己决定重开——年龄变化恰恰是图生图微调该干的事。
- 换时期 = 在 `periods` 里**新建条目**。旧时期条目一旦建好就不改文本（图可能已生成）。

## personality — 性格

只从原文行为归纳（"遇险先退半步，藏拙"），不引申、不文学化。

## prompt_body 五段

按 `prompt-style.md` 写。角色时期提示词的主体段 =

```
固定主体锚点（原文照抄） + 固定特征（若有） + 本时期服饰（颜色/材质/纹样/配饰/武器）
```

服饰必须符合所属势力该阶级的 `costume_rule`——不同势力不同阶级同框时不许串。

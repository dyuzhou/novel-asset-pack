# 阶段 03 · 主资产

先建立身份档案，再用当前 Agent 实际可调用的图片能力生成标准参考图。角色档案包含稳定 ID、原著出处、性别/年龄（只按原著）、身份/势力/等级、体型、五官、发型、服饰和视觉识别锚点。场景档案包含时代、空间结构、材质、色彩、固定物件和视觉锚点；场景基准图不带剧情人物。道具档案记录所属者、材质、结构、尺寸、功能、外观特征和出处；道具图独立呈现道具。

每个主资产至少生成一张标准参考图。人物先生成标准正面全身主参考图并等待人工确认，确认后再生成面部、侧面、背面、服装细节或表情参考。其他视角必须引用已批准主图，不得重新自由设计身份。

资产登记唯一身份、递增版本、文件、完整提示词、提示词版本、审批状态和来源。人工批准的文件不覆盖；重做创建新版本。没有实际文件或生成工具时，记录真实阻塞。
